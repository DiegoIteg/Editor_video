# Checklist de Qualidade do Vídeo

- [ ] Enquadramento passado (`checklist_enquadramento.md`).
- [ ] **Sem erros do sistema à vista** (ex.: lançar orçamento sem erro).
- [ ] Ritmo: cada plano dá tempo de ler; transições suaves.
- [ ] Movimento suave (sem tremer); sem saltos de frame.
- [ ] Áudio: voz normalizada (−16 LUFS), música com ducking, sem cliques.
- [ ] Sincronia voz↔ecrã: o que se ouve é o que se vê.
- [ ] PT-PT correto; números `1.234,56`; datas `DD/MM/AAAA`.
- [ ] Nome do ficheiro claro; formato e tamanho certos.
