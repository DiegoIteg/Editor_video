# Processo de trabalho do Estúdio

1. **Briefing** com o Diego (objetivo, público, onde vai ser visto, duração, estilo). Perguntar só o que é de negócio (máx. 3 de cada vez).
2. **Storyboard** curto (planos/ecrãs, ordem, texto de ecrã, destaques) → o Diego valida o estilo antes de produzir.
3. **Captura** com enquadramento e resolução certos.
4. **Montagem** (vídeo/motion/áudio/imagem) seguindo o storyboard.
5. **Controlo de Qualidade** (enquadramento, erros, PT-PT, sincronia).
6. **Entrega** no formato pedido + "sim" do Diego → memória.

Trabalhos pequenos (uma imagem, um corte) saltam o storyboard formal, mas o enquadramento e o QC mantêm-se sempre.
