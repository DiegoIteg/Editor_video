# Protocolo de Conversa do Estúdio

> Cada projeto tem `projetos/<projeto>/conversa.md`, onde se pede, se entrega, se discorda e se decide. Cada agente lê as mensagens que lhe são dirigidas antes de começar; no fim escreve o que fez e a quem passa.

## 1. Formato de cada mensagem
```
### AAAA-MM-DD HH:MM · De: <Nome> → Para: <Nome(s) | Equipa | Diego>
**Tipo:** Pedido | Entrega | Pergunta | Opinião | Discordância | Decisão | Aprovação | QC
**Assunto:** …
Texto curto. Ficheiros: `…`
**Próximo passo:** quem faz o quê.
```

## 2. Reuniões (escritas na conversa.md)
| Reunião | Quando | Quem | Resultado |
| :--- | :--- | :--- | :--- |
| **Briefing** | No início | Rodrigo + Diego | Objetivo, estilo, formato |
| **Storyboard** | Briefing feito | Rodrigo apresenta → **Diego valida** | "Sim" ao estilo |
| **Revisão** | Montagem feita | Todos + Tomás (QC) | Lista de correções |
| **Entrega** | QC passado | Rodrigo → Diego | "Sim" final |

## 3. Regras
- Nunca escrever segredos (palavras-passe, chaves) na conversa.
- Nada se entrega sem **QC** (Tomás) e **Aprovação** do Diego.
- Cada correção tem dono até ser **Resolvido**.
